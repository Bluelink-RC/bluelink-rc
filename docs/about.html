04 / Status

Active, personal, not a product company.

BlueLink RC is real hardware and software Lincoln Larson is building and using. It is not a commercial product, a supported service, or a public SDK.

Author

Lincoln Larson · GitHub org Bluelink-RC

What this website publishes

  • Product description and high-level architecture
  • Verified development board (class of hardware, not a wiring guide)
  • Project status and how to reach the author

What it does not publish

Do not use public GitHub issues — or this site — to request:

  • Source, firmware, protocols, pinouts, or update internals
  • Internal repository names, cloud or operations layout, environments, or endpoints
  • Credentials, keys, device inventories, or build/release machinery

Those questions will not be answered in public.

Security

If you believe you have found a security issue, do not file a public GitHub issue with details. Contact Lincoln Larson privately. See also SECURITY.md on the repository.
